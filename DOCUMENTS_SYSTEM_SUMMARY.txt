================================================================================
DATABASE SCHEMA OVERVIEW
================================================================================

Core Tables (10):
- documents          : Main document container
- document_blocks    : Individual blocks (paragraphs, tables, charts, etc)
- document_permissions : Granular access control (viewer/editor/admin)
- document_collaborators : Real-time presence & cursor tracking
- document_comments  : Inline comments per block
- document_comment_replies : Threaded comment replies
- document_versions  : Version history snapshots
- document_folders   : Folder structure for organization
- document_shares    : Shareable links with unique tokens
- document_activities : Audit log of all changes

Supported Block Types (13):
- paragraph, heading1, heading2, heading3
- table, chart, calendar, kanban
- image, embed, callout
- code, quote, divider, checklist

Indexes (28):
- org_id (fast org-wide queries)
- document_id (fetch all blocks)
- position (ordered retrieval)
- created_by, user_id (track ownership)
- is_online (real-time presence)
- created_at (activity feed)
- And more for optimal performance

Row-Level Security (RLS):
- 20+ policies enforcing multi-tenant isolation
- Document access based on creator or explicit permissions
- Permission expiration support
- Role-based edit restrictions (viewer/editor/admin)

Triggers & Functions:
- Auto-update timestamps (created_at, updated_at)
- Auto-increment version numbers
- Generate random share tokens

KEY FEATURES
================================================================================

1. Flexible Block Structure
   - 13+ block types (paragraph, table, chart, kanban, etc)
   - JSONB content for type-specific data
   - Linked to CRM records (clients, projects, invoices)

2. Granular Permissions
   - Three roles: viewer (read), editor (read+write), admin (full control)
   - Per-document permissions
   - Expiring tokens for temporary access
   - Admin can manage all aspects

3. Real-time Collaboration
   - Cursor position tracking
   - Presence awareness (who's online)
   - Subscriber color coding
   - Multi-user editing support

4. Comments & Discussion
   - Inline comments per block
   - Threaded replies
   - Comment resolution
   - User mentions (future)

5. Version Control & Undo
   - Automatic version snapshots
   - Full document state captured (all blocks)
   - Rollback to any previous version
   - Change descriptions for tracking

6. Sharing Options
   - Public view (read-only sharing)
   - Public edit (collaborative sharing)
   - Password protected
   - Client-only (restricted access)
   - Expiration dates

7. Organization
   - Folder structure (nested folders)
   - Document tagging
   - Pin/unpin important docs
   - Archive old documents

8. Audit Trail
   - Complete activity log
   - Track who did what when
   - Useful for compliance
   - Helps debug issues

9. Performance Optimized
   - 28 indexes for fast queries
   - Efficient pagination support
   - Soft deletes for undo
   - GIN index on tags array

10. Security
    - Row-level security on all tables
    - Enforced multi-tenant isolation
    - Permission expiration
    - Audit trail for accountability
